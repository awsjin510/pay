# 推廣素材與時程

目標：3 個月內新增 300 筆網站投稿。每個管道用不同的 `ref`，之後用 `npm run review -- stats` 看哪個管道帶來最多投稿。

## 追蹤代碼

在連結後面加 `?ref=代碼`，例如 `https://pay.operation.tw/submit/?ref=podcast`。

| 管道 | 代碼 | 建議連結 |
|---|---|---|
| Podcast《操作一下》 | `podcast` | `https://pay.operation.tw/submit/?ref=podcast` |
| Facebook | `fb` | `https://pay.operation.tw/?ref=fb` |
| PTT | `ptt` | `https://pay.operation.tw/?ref=ptt` |
| Dcard | `dcard` | `https://pay.operation.tw/?ref=dcard` |
| Threads | `threads` | `https://pay.operation.tw/?ref=threads` |
| LinkedIn | `linkedin` | `https://pay.operation.tw/?ref=linkedin` |
| AWS User Group 等技術社群 | `community` | `https://pay.operation.tw/sectors/cloud-security/?ref=community` |
| 季度報告 | `report` | 已內建在報告頁 |
| 分享圖 | `share` | 已內建在分享按鈕 |

> 訪客從任何帶 `ref` 的連結進站，網站會在該次瀏覽記住來源，之後投稿就會算到這個管道。

## Podcast 口播（約 60 秒，可放片頭或片尾）

> 最近我做了一個小工具，叫「科技業薪資參考」，網址是 pay.operation.tw。
>
> 它把兩千多筆工程師匿名分享的薪資，和上市櫃公司依法揭露的官方薪資、勞動部的職類薪資調查放在一起。你可以查聯發科、台積電、華碩，打 PTT 代號像「螃蟹」「滷肉」也找得到；雲端、資安、資訊服務業也有專區。
>
> 完全免費，不用註冊，也不用分享才解鎖。如果你願意，花 30 秒匿名分享自己的薪資，送出後馬上能看到你在同產業排在 PR 多少，還能下載一張不含金額的分享圖。資料越多，大家談薪水就越有底氣。
>
> 連結放在節目資訊欄，歡迎分享給需要的夥伴。

**單集企劃建議：「台灣工程師薪水真相」**（可用 `podcast-script-generator` 產出完整腳本）
1. 為什麼網路上的薪資資訊很難比：單位混亂、職級不通用、資料舊。
2. 網友回報 vs 官方揭露：聯發科網友總年薪中位數 215 萬，官方非主管中位數 355 萬，差在哪？
3. 同樣是資訊人員，資訊服務業（63）10.5 萬、電子零組件製造 9.2 萬、教育業 5.2 萬。
4. 雲端與資安：SRE／DevOps 月薪中位數 8.8 萬，資安研究員 6.3 萬。
5. 呼籲：匿名分享，讓資料更準。

## Facebook 貼文

> 最近把一個放在心裡很久的想法做出來了：「科技業薪資參考」pay.operation.tw
>
> 每次有夥伴在問 offer 該不該接、要開多少，大家能參考的不外乎 PTT 上的零星分享、要付費才看得到的網站，或是好幾年前的試算表。資料有，但單位亂、公司名稱寫法五花八門，很難真的拿來比較。
>
> 所以我做了幾件事：
> ・把一份兩千多筆的工程師薪資表單整理過，萬和元統一、明顯填錯的排除，「螃蟹」「滷肉」「海邊」這些 PTT 代號也都對應到正確的公司
> ・放進公開資訊觀測站的官方非主管薪資，還有勞動部各職類、各行業的薪資調查，讓網友回報和官方數字可以互相對照
> ・雲端／資安、資訊服務業另外整理成專區，SRE、DevOps、資安研究員都看得到
>
> 對我來說，最重要的是兩件事：完全免費、不用分享才解鎖；也盡量保護填寫的人，罕見職稱會自動歸類、人名會遮蔽，任何人都能申請下架。
>
> 如果你願意，也歡迎花 30 秒匿名分享自己的薪資～送出後會馬上看到你在同產業的 PR 值，還能下載一張不含金額的分享圖。資料越多，大家談薪水就越有底氣!!
>
> 👉 https://pay.operation.tw/?ref=fb
>
> 有任何建議或發現數字怪怪的，也很歡迎告訴我，會持續調整。

## PTT（Tech_Job／Salary）

**發文前先確認板規：** Tech_Job 2026-03 的新板規禁止造謠與人身攻擊，對推廣性質的文章也可能有限制。建議先寄信問板主，或用「開放資料分享」的角度發，不要寫成廣告。

> [分享] 整理了科技業薪資開放資料（含官方揭露對照）
>
> 把一份 2,100 筆左右的工程師薪資表（純軟／系統廠／IC 設計）重新整理，放在 pay.operation.tw
>
> 做了這些事：
> 1. 月薪單位統一成「萬」（原本約 380 筆填成元），明顯打錯的排除，不計入統計
> 2. 公司名稱合併，PTT 代號也對應：螃蟹=瑞昱、滷肉=聯詠、肉鬆=廣達、海邊=鴻海、P=群聯（IC）
> 3. 每間上市櫃公司旁邊放公開資訊觀測站的非主管薪資中位數，可以和網友回報對照
> 4. 勞動部職類別薪資：資訊及通訊專業人員在 25 個行業的薪資比較
> 5. 彙總結果以 CC BY 4.0 提供 CSV 下載
>
> 免費、不用登入。也可以匿名補資料，有填心得的投稿會人工審核。
> 數字有問題、或希望某筆下架，網站上有申請表。
>
> https://pay.operation.tw/?ref=ptt

## 授權洽詢信範本（給其他公開薪資表單的擁有者）

> 主旨：想將您整理的薪資表單合併到「科技業薪資參考」，請問是否同意授權
>
> 您好，我是「科技業薪資參考」（pay.operation.tw）的維護者。這是一個免費、不需註冊的科技業薪資查詢網站，目前整合了網友匿名分享、公開資訊觀測站的官方薪資揭露，以及勞動部職類別薪資調查。
>
> 在網路上看到您整理的「〔表單名稱〕」，內容對求職者很有幫助。想請問您是否願意授權本站合併這份資料。我們會：
> 1. 在網站與資料說明頁標註來源與您的名稱（或依您希望的方式）；
> 2. 統一單位、排除明顯錯誤，並做去識別處理（罕見職稱歸類、人名遮蔽、人身攻擊不公開）；
> 3. 只以彙總統計開放 CSV（CC BY 4.0），不公開逐筆原始資料；
> 4. 隨時依您或當事人的要求移除。
>
> 若您同意，回覆這封信即可；若有任何條件或疑慮，也歡迎提出。謝謝您！

## 成效追蹤

- **投稿量與來源**：`npm run review -- stats`，看各 `ref` 帶來的投稿數與每週走勢。
- **流量**：Cloudflare Dashboard → Web Analytics → pay.operation.tw，看各頁瀏覽數與來源網站。
- **轉換率**：投稿頁瀏覽數 ÷ 實際投稿數，低於 5% 時檢查表單是否太長。
- **品質**：`npm run review -- recent` 抽查自動核准的投稿。
